## ⚙️ Mes projets

### **[Campus Rate](https://github.com/KevinEJean/camp_api)** | API pour gestion de campus avec appréciation

<p align="justify">
  CampusRate API est une application REST dédiée à la gestion centralisée des emplacements et des appréciations sur le campus, avec une persistance des données assurée par MongoDB. L'application intègre une authentification par jeton JWT et un contrôle d'accès basé sur les rôles (RBAC), en plus de la journalisation des requêtes et des erreurs ainsi que d'un filtrage d'IP par liste blanche.
</p>
